# Hoja de vida web — Daniel Vergel

Página web local con la hoja de vida de **Daniel Enrique Vergel González Rubio**, en estilo moderno tech.

## Cómo verla

1. Abre el archivo `index.html` con doble clic, **o**
2. Desde PowerShell, en esta carpeta:

```powershell
start index.html
```

También puedes servirla con un servidor simple:

```powershell
npx --yes serve .
```

Luego abre la URL que muestre la terminal (por ejemplo `http://localhost:3000`).

## PDF

Usa el botón **PDF** del encabezado (o `Ctrl+P`) y elige “Guardar como PDF”. Hay estilos de impresión optimizados.

## Archivos

| Archivo                    | Rol                          |
|----------------------------|------------------------------|
| `index.html`               | Estructura y contenido       |
| `styles.css`               | Diseño tech (dark + cyan)    |
| `script.js`                | Menú, animaciones, impresión |
| `assets/foto-perfil.jpg`   | Foto de perfil (de la T.P.)  |

Para cambiar la foto, reemplaza `assets/foto-perfil.jpg` por otra imagen con el mismo nombre (recomendado: rostro centrado, fondo limpio).
