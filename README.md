# Hoja de vida web — Daniel Vergel

Página web con la hoja de vida de **Daniel Enrique Vergel González Rubio**, en estilo moderno tech.

## En línea (GitHub Pages)

**URL pública:** https://lider11.github.io/cv-daniel-vergel/

Repositorio: https://github.com/lider11/cv-daniel-vergel

## Cómo verla en local

1. Abre el archivo `index.html` con doble clic, **o**
2. Desde PowerShell, en esta carpeta:

```powershell
start index.html
```

También puedes servirla con un servidor simple:

```powershell
npx --yes serve .
```

Luego abre la URL que muestre la terminal (por ejemplo `http://localhost:3000`).

## PDF y compartir

- **Descargar PDF:** botón en el encabezado, hero y contacto → `assets/CV-Daniel-Vergel.pdf`
- **Imprimir:** botón *Imprimir* o `Ctrl+P` (estilos optimizados para A4)
- **Al compartir el enlace** (WhatsApp, LinkedIn, X): se muestra tarjeta con imagen Open Graph (`assets/og-image.jpg`)

## Archivos

| Archivo                    | Rol                          |
|----------------------------|------------------------------|
| `index.html`               | Estructura y contenido       |
| `styles.css`               | Diseño tech (dark + cyan)    |
| `script.js`                | Menú, animaciones, impresión |
| `assets/foto-perfil.jpg`   | Foto de perfil (de la T.P.)  |

Para cambiar la foto, reemplaza `assets/foto-perfil.jpg` por otra imagen con el mismo nombre (recomendado: rostro centrado, fondo limpio).
